# SS Gulf Shipping website

Static website for SS Gulf Shipping (freight forwarding, NVOCC, trucking, container trading; offices in Karachi and Lisbon).

- Pages: `index.html`, `about.html`, `services.html`, `contact.html`, `privacy.html`, `terms.html`
- Generated by `node build.js` (no dependencies). Edit `build.js` and `assets/`, then rebuild.
- 3D viewers use three.js from the jsDelivr CDN, so an internet connection is needed for 3D. Without it the pages show photos.
- To preview locally: `npx serve .` or open `index.html` in a browser.
